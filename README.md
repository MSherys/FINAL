
**Описание проекта**  
Это веб-сервер для управления задачами с возможностью повторения. Каждая задача содержит:  
- Название  
- Комментарий  
- Дедлайн  
- Правило повтора (ежегодно, через N дней, по дням недели/месяца)  

При выполнении задачи:  
- С повторением → переносится на новую дату по правилу  
- Без повтора → удаляется  


**Запуск сервера**  
1. Скачайте проект `go_final_project`  
2. Откройте папку в VS Code (File → Open Folder)  
3. В терминале выполните:  
   go run .
4. Перейдите в браузере:  
   `http://localhost:7540`  
**Тестирование**  
1. Проверьте настройки в `tests/settings.go`:  
   Port = 7540
   DBFile = "../scheduler.db"
2. Запустите сервер (`go run .`)  
3. В отдельном терминале выполните:  
   go test ./tests
