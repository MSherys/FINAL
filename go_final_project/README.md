# Файлы для итогового задания

В директории `tests` находятся тесты для проверки API, которое должно быть реализовано в веб-сервере.

Директория `web` содержит файлы фронтенда.

Данный проект представляет собой web сервер, реализующий индивидуальный планировщик задач
Задача состоит из наименования, комментария, даты дедлайна, правила повторения.
Задачи могут повторяться по заданному правилу повторения: ежегодно, через какое-то количество дней, в определённые дни месяца или недели. Если отметить такую задачу как выполненную, она переносится на следующую дату в соответствии с правилом. Если правило повторения отсутствует, то задача удаляется после отметки о выполнении.

Задания повышенной трудности не выполнялись.

Инструкция по запуску кода локально: 1) Скопируйте папку с проектом (go_final_project) на ваш ПК 2)Запустите Visual Studio Code. В главном меню выбрать File - OpenFolder и укажите путь к папке go_final_project (в саму папку заходить не надо) 3)В главном меню выбрать Terminal - NewTerminal. В появившемся внизу окне выбрать закладку terminal и ввести команду go run .   4)Запустить браузер и ввести адрес http://localhost:7540/

Инструкция по запуску тестов: Откройте проект в Visual Studio Code. Слева в навигационном окне раскройте директорию tests и откройте файл settings.go Проверте что все настройки соответствуют требованию

var Port = 7540
var DBFile = "../scheduler.db"
var FullNextDate = false
var Search = false
var Token = ``

Чтобы запустить проверку тестов откройте проект в Visual Studio Code и выполните команду go run .   Далее в другом терминале (например Git Bash) перейдите в папку go_final_project и запустите команду go test ./tests
